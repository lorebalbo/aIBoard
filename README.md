# aIBoard

Machine Learning in a **Declarative Way**.

Select your preferred dataset and model, easily configure validation, and start training with a single click. Explore detailed reports, compare results, and keep track of all your experiments in a simple and intuitive way.

## How to Use

You can use aIBoard directly from the Julia REPL with the [aIBoard.jl]() package or through a graphical interface.

### aIBoard.jl

Run machine learning experiments by simply setting up a JSON file.

For more information on using aIBoard.jl in the REPL, see the [documentation]().

### GUI

This is the graphical interface for [aIBoard.jl]().

For more information on using the GUI, see the [user documentation]().

## Developers

To contribute to the development and growth of aIBoard, it is recommended to read the [technical documentation]() to become familiar with the project structure and design details.

Note that this repository serves as the main repository for aIBoard and is composed of submodules, one for each component of aIBoard.
